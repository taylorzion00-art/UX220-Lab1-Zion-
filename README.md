# The favourite thing ive wrote 
Hi my name is Zion Taylor and my favourite thing ive ever written would probably be when i wrote a farewell speech for my grandmothers funeral. I think that was my favourite because i got to say my final goodbyes and how i really felt about my grandmother as well as the impact shes had in my life. 

The funeral proceeding were huge so i was saying this speech in front of a large audience that was received well with claps and cheers.
